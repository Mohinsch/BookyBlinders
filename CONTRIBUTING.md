# Contributing to Booky Blinders

First off, thank you for considering contributing to Booky Blinders! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## 🛠️ Development Workflow

1. **Fork the repository** and clone it locally.
2. **Create a branch** for your feature or bug fix:
   `git checkout -b feature/my-awesome-feature` or `git checkout -b fix/annoying-bug`
3. **Install dependencies** using `npm install`.
4. **Make your changes** and test them locally.

## 📏 Code Style & Quality

We use **Biome** to maintain a consistent code style and catch issues early.

- Before committing, format your code: `npm run format`
- Check for linting errors: `npm run lint`
- Ensure all tests pass: `npm test`

*Note: If you use VS Code, we highly recommend installing the Biome extension and setting it as your default formatter.*

## 💾 Commit Convention

Please write clear, concise commit messages. We loosely follow the Conventional Commits specification:

- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation changes
- `refactor:` for code refactoring without changing behavior
- `chore:` for routine tasks, tooling, or dependency updates

*Example:* `feat: add reading progress bar to library cards`

## 🚀 Submitting a Pull Request

1. Push your branch to your fork.
2. Open a Pull Request against the `main` branch of this repository.
3. Describe your changes in detail in the PR description.
4. Link any relevant issues.

Thank you for your contribution!
